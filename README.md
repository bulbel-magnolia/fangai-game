# 防癌人生分支簿

「医声有AI」防癌科普游戏 · ClinicalKey AI

一款由你的选择决定走向的第一人称沉浸式科普故事。四条主线(日常起居 / 饮食营养 / 筛查决策 / 运动作息)覆盖癌症预防的核心场景,每个选择决定你的健康人格,最终命中四种结局之一:

| 结局 | 对应人格 |
|---|---|
| 科技赋能型 | 科技控 · AI 防癌先锋 · 医疗 AI 达人 |
| 理性科学型 | 冷静靠谱 · 科学防癌达人 · 理性应对者 |
| 焦虑敏感型 | 细腻敏感 · 易焦虑 · 缺乏安全感 |
| 佛系忽视型 | 心态佛系 · 大大咧咧 · 重视不足 |

## 技术栈

纯静态 H5:HTML + CSS + 原生 JavaScript,无构建。本地双击 `index.html` 即可运行。

## 在线体验

部署在 GitHub Pages。

## 结构

```
.
├── index.html       # 单页结构
├── style.css        # 极简文字流设计
├── data.js          # 剧本数据(28 题 × 4 选项 + 4 结局)
├── game.js          # 引擎(状态机 + 渲染 + 结局判定 + 二维码)
└── lib/
    └── qrcode.min.js  # QR 码生成(MIT, kazuhikoarase)
```

## 结局判定优先级

`tech ≥4 → anxious ≥3 → healthy ≥5 → risk ≥4 → 兜底取最高项`
